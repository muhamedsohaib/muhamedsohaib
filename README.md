## Muhammad Sohaib

E-commerce and digital operations, Dubai. I own Amazon marketplace execution end to
end — catalog health, Seller Central troubleshooting, and the automation that keeps a
2,000+ SKU environment consistent as it scales.

Most of my work starts as an operational failure that keeps recurring. Suppressed
listings, broken parent-child variations, feed uploads that reject without saying why.
The interesting part is not fixing one — it is turning the pattern into a validation
rule, an upload-ready file, or a tool that stops it happening again.

**Currently building**

- **Project Zero** — an Amazon seller operating layer combining seller data, competitor
  intelligence, deterministic analytics, seller-specific memory and controlled
  automation. Auditable tools with human approval gates rather than black-box agents.
- **Marketplace Decision Brief Generator** — a browser-based CSV tool that compares
  marketplace KPIs against targets and guardrails, ranks operating gaps, and converts
  them into prioritised actions. Keeps observed facts, hypotheses, recommendations and
  unknowns explicitly separated.
